This repository is a customized deployment setup based on the official Frappe Docker project.

It is used to deploy **ERPNext** in a self-hosted environment with:

* Docker-based deployment
* MariaDB database
* Redis services
* Persistent data storage
* Traefik reverse proxy
* Internal domain access
* Production-oriented configuration

The repository also includes deployment documentation and scripts for generating the production Docker Compose configuration.

## Purpose

This fork is maintained specifically for this ERPNext deployment and its future maintenance, configuration, and upgrades.

The original Frappe Docker configuration is preserved within the repository as the foundation for the deployment.
